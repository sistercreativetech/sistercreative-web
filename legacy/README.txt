WEBSITE SISTER CREATIVE

Cara memasang di Hostinger:
1. Ekstrak file ZIP.
2. Masuk ke hPanel Hostinger.
3. Buka Websites > Manage > File Manager.
4. Buka folder public_html.
5. Hapus atau pindahkan index lama jika memang ingin menggantinya.
6. Unggah index.html, style.css, dan script.js langsung ke public_html.
7. Buka https://sistercreative.tech lalu lakukan hard refresh (Ctrl+F5).
